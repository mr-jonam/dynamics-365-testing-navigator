Before you use this guide

Is RSAT a universal Dynamics 365 testing tool?

The linked Microsoft documentation scopes RSAT to Finance and Operations apps. Confirm applicability before making a tooling decision.

Does Test Studio cover all Power Apps types?

The linked reference is for canvas apps. Do not infer coverage for other application types.
