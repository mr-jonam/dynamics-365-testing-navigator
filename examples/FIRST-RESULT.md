# First result: Dynamics 365 Testing Navigator

This is a fictional, synthetic reading exercise. The brief below is an editorial illustration, not a captured tool result or evidence from a customer system.

## Start with one situation

A team says that a Dynamics change needs regression testing, but has not confirmed whether the change belongs to Finance and Operations, a CRM application or a canvas app.

## Keep the input small

```text
Product label supplied: Dynamics 365.
Known: a regression discussion is needed.
Uncertain: application family and affected journey.
```

## A useful discussion question

> Which Dynamics application family and business journey are actually changing?

Identify the application family before interpreting the RSAT or Power Apps references. The guide does not select a universal tool or access an environment.

## Try it yourself

1. Read the [decision guide](../GUIDE.md).

3. If useful, open the mini tool using the [local preview instructions](../README.md#start-here) and represent the same uncertainty with its available choices.
